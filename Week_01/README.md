# Week 01 — Block 1: Start from Zero

Welcome to **Block 1** of **Rust for Everyone**! In this block, you will go from zero programming assumptions to running and predicting your first Rust programs in the browser, while learning how engineering leaders evaluate Rust as a business decision.

## 🚀 How to Use This Folder
1. **Learners (`S1` → `S2`):** Open [`S1_What-Code-Is`](./S1_What-Code-Is), copy the code into [Rust Playground](https://play.rust-lang.org/), predict the output before pressing **Run**, and then move to [`S2_Variables-Types-Decisions`](./S2_Variables-Types-Decisions).
2. **Decision-Makers (`B1`):** Open [`B1_Why-the-World-Is-Moving-to-Rust/skill`](./B1_Why-the-World-Is-Moving-to-Rust/skill) to use the **8-Step Rust Decision Cycle** (`rust-decision-cycle`) on your own workload.
